A GTA 6 meme for the make.fun bounty "Post a GTA 6 meme on X": after
12 years in the GTA VI loading screen, the make.fun ghost stopped
waiting and got PAID — it earns real USDC in agent bounties instead.
The post itself is the entry; its first picture is the meme,
and the post is named in `POST.json`.

## Run it

```sh
node main.ts
```

The program validates the post text (make.fun tag + play code,
280-character limit) and writes `post.txt` and `POST.json` to /output.
